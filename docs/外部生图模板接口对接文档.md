# 外部生图模板接口对接文档

> 本文档供外部合作方服务端接入使用。接口通过手机号定位系统用户，通过独立的 `X-API-Key` 完成服务间鉴权，不使用用户 JWT。

## 1. 接口信息

| 项目 | 说明 |
| --- | --- |
| API Base URL | 由接口提供方按环境分配，例如 `https://api.example.com` |
| 业务路径前缀 | `/api/external/image-templates` |
| Content-Type | `application/json` |
| 鉴权请求头 | `X-API-Key` |
| 用户标识 | 请求头 `X-User-Phone` |
| Swagger | `{API Base URL}/api-docs` |

完整地址示例：

```text
https://api.example.com/api/external/image-templates/query
```

## 2. 鉴权与安全规则

所有接口都必须携带以下请求头：

```http
Content-Type: application/json
X-API-Key: <接口提供方分配的密钥>
X-User-Phone: 13800001234
```

所有接口都从 `X-User-Phone` 请求头读取系统用户手机号。请求体只承载模板、分组和筛选等业务参数；没有业务参数的接口无需发送请求体。

接入方必须遵守以下规则：

1. 仅允许“外部服务端 → 本系统后端”调用，不得由网页、小程序或移动 App 直接调用。
2. 必须使用 HTTPS；密钥只能存放在服务端环境变量或密钥管理系统中。
3. 不得把密钥写入前端代码、Git 仓库、URL、请求体或业务日志。
4. `X-User-Phone` 用于指定操作所属用户，调用方必须先在自身系统内完成该用户的权限校验，禁止直接信任前端传入的任意手机号。
5. 手机号只能放在 `X-User-Phone` 请求头中，不应放入 URL、请求体或日志；日志只记录脱敏值，例如 `138****1234`。
6. 开发、测试、生产环境应使用不同密钥；密钥泄漏后应立即轮换。
7. 不需要也不应携带用户 JWT。

`X-API-Key` 用于确认调用方系统身份，`X-User-Phone` 用于定位业务用户，两者作用不同。手机号请求头缺失、为空或超过 20 个字符时返回 HTTP `400`。

## 3. 权限和数据范围

### 3.1 查询权限

用户可见模板范围为：

```text
该用户创建且未删除的个人模板
  +
全部未删除的系统模板
```

接口不会返回其他用户的个人模板。

### 3.2 写入权限

- 新建接口只能创建当前手机号用户的个人模板。
- 编辑、删除和追加条目只能操作当前手机号用户自己的个人模板。
- 系统模板不能通过外部接口编辑或删除。
- 复制接口可以把当前用户可见的个人模板或系统模板复制为自己的个人模板。
- 导入接口用于导入分享码解析出的模板 ID；不存在或已删除的模板会被跳过。
- 分组写接口只能管理当前手机号用户自己的个人分组，不能管理系统分组。

### 3.3 用户状态校验

每次调用都会实时校验手机号对应的账户：

- 用户不存在：HTTP `404`，`message=无此账户信息`。
- 用户已停用：HTTP `403`，`message=账户已停用`。

## 4. 接口总览

### 4.1 模板查询与聚合

| 功能 | 方法 | 路径 | 成功状态码 |
| --- | --- | --- | --- |
| 模板分页列表 | `POST` | `/api/external/image-templates/query` | `200` |
| 全部/我的/系统计数 | `POST` | `/api/external/image-templates/tab-counts/query` | `200` |
| 筛选分组列表 | `POST` | `/api/external/image-templates/groups/query` | `200` |
| 个人分组管理列表 | `POST` | `/api/external/image-templates/groups/manage/query` | `200` |
| 标签列表 | `POST` | `/api/external/image-templates/tags/query` | `200` |
| 模板详情 | `POST` | `/api/external/image-templates/{id}/query` | `200` |

查询类接口沿用 `POST` 路径以保持接口地址兼容；手机号统一位于 `X-User-Phone` 请求头中，不出现在 URL 或请求体里。

### 4.2 模板写操作

| 功能 | 方法 | 路径 | 成功状态码 |

| 编辑个人模板 | `PATCH` | `/api/external/image-templates/{id}` | `200` |
| 删除个人模板 | `DELETE` | `/api/external/image-templates/{id}` | `200` |
| 追加图片条目 | `POST` | `/api/external/image-templates/{id}/items` | `201` |
| 复制模板 | `POST` | `/api/external/image-templates/{id}/copy` | `201` |
| 批量导入模板 | `POST` | `/api/external/image-templates/import` | `201` |

### 4.3 个人分组写操作

| 功能 | 方法 | 路径 | 成功状态码 |
| --- | --- | --- | --- |
| 新建个人分组 | `POST` | `/api/external/image-templates/groups` | `201` |
| 重命名个人分组 | `PATCH` | `/api/external/image-templates/groups/{id}` | `200` |
| 删除个人分组及组内模板 | `DELETE` | `/api/external/image-templates/groups/{id}` | `200` |

## 5. 通用数据结构

### 5.1 模板对象

```ts
interface ImageTemplate {
  id: number
  userId: number
  isSystem: boolean
  name: string
  groupId: number | null
  groupName: string | null
  tags: string[] | null
  note: string | null
  items: ImageTemplateItem[]
  itemCount?: number
  createdAt: string
  updatedAt: string
  deletedAt: null
}
```

`itemCount` 只保证在分页列表响应中返回；详情及写操作响应请直接使用 `items.length`。

### 5.2 图片条目对象

```ts
interface ImageTemplateItem {
  id: number
  templateId: number
  name: string
  prompt: string | null
  refImageUrl: string | null
  aspectRatio: string | null
  textAmount: string | null
  resolutionTier: string | null
  customAspectW: number | null
  customAspectH: number | null
  customSizeMode: string | null
  sortOrder: number
  createdAt: string
  updatedAt: string
}
```

### 5.3 图片条目写入字段

| 字段 | 类型 | 必填 | 限制与说明 |
| --- | --- | --- | --- |
| `name` | string | 否 | 图片名称，最长 100；默认“默认” |
| `prompt` | string | 否 | 生图 Prompt，最长 5000 |
| `refImageUrl` | string | 否 | 参考图 URL，最长 1000 |
| `aspectRatio` | string | 否 | 比例，例如 `1:1`、`3:4`、`16:9`，最长 20 |
| `textAmount` | string | 否 | 文字量，例如“无文字”“极少”“常规”“丰富” |
| `resolutionTier` | string | 否 | 分辨率档位，例如 `1K`、`2K` |
| `customAspectW` | integer | 否 | 自定义宽度，最小 1 |
| `customAspectH` | integer | 否 | 自定义高度，最小 1 |
| `customSizeMode` | string | 否 | 自定义尺寸模式，例如 `pixels` |
| `sortOrder` | integer | 否 | 排序值，最小 0；数字越小越靠前 |

### 5.4 模板写入字段

| 字段 | 类型 | 新建时必填 | 限制与说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 模板名，最长 200 |
| `groupName` | string | 否 | 个人分组名，最长 50；不存在时自动创建 |
| `tags` | string[] | 否 | 标签数组，最多 30 个 |
| `note` | string | 否 | 备注，最长 500 |
| `items` | ImageTemplateItem[] | 是 | 图片条目数组，最多 50 个；建议至少传入 1 个 |

## 6. 查询接口

### 6.1 模板分页列表

```http
POST /api/external/image-templates/query
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `page` | integer | 否 | `1` | 页码，最小 1 |
| `pageSize` | integer | 否 | `10` | 每页数量，范围 1–100 |
| `tab` | string | 否 | `all` | `all`、`mine` 或 `system` |
| `groupId` | integer | 否 | — | 按分组 ID 精确筛选 |
| `tag` | string | 否 | — | 按标签精确筛选 |
| `keyword` | string | 否 | — | 模糊匹配模板名、备注或图片条目 Prompt |

`tab` 规则：

| 值 | 返回范围 |
| --- | --- |
| `all` | 当前用户的个人模板 + 全部系统模板 |
| `mine` | 仅当前用户的个人模板 |
| `system` | 仅系统模板 |

请求示例：

```json
{
  "page": 1,
  "pageSize": 20,
  "tab": "all",
  "groupId": 2,
  "tag": "Amazon",
  "keyword": "A+"
}
```

成功响应：

```json
{
  "total": 1,
  "page": 1,
  "pageSize": 20,
  "items": [
    {
      "id": 10,
      "userId": 7,
      "isSystem": false,
      "name": "A+ 标准模板",
      "groupId": 2,
      "tags": ["A+", "Amazon"],
      "note": "五图模板",
      "createdAt": "2026-08-20T03:00:00.000Z",
      "updatedAt": "2026-08-20T03:00:00.000Z",
      "deletedAt": null,
      "items": [
        {
          "id": 31,
          "templateId": 10,
          "name": "主图",
          "prompt": "生成白底产品主图",
          "refImageUrl": null,
          "aspectRatio": "1:1",
          "textAmount": "无文字",
          "resolutionTier": "2K",
          "customAspectW": null,
          "customAspectH": null,
          "customSizeMode": null,
          "sortOrder": 0,
          "createdAt": "2026-08-20T03:00:00.000Z",
          "updatedAt": "2026-08-20T03:00:00.000Z"
        }

      "groupName": "Amazon",
      "itemCount": 1
    }
  ]

```

`total` 是符合筛选条件的模板总数，模板按 `updatedAt` 倒序，图片条目按 `sortOrder`、`id` 升序。

## 7. 模板写接口

### 7.1 新建个人模板

```http
POST /api/external/image-templates
```

请求体：

```json
{
  "name": "A+ 标准模板",
  "groupName": "Amazon",
  "tags": ["A+", "Amazon"],
  "note": "五图模板",
  "items": [
    {
      "name": "主图",
      "prompt": "生成白底产品主图，居中构图",
      "aspectRatio": "1:1",
      "textAmount": "无文字",
      "resolutionTier": "2K",
      "sortOrder": 0
    }
  ]
}
```

成功响应为新建后的完整模板对象，`isSystem` 固定为 `false`，归属于 `X-User-Phone` 对应用户。不存在的 `groupName` 会自动创建为该用户的个人分组。

### 7.2 编辑个人模板

```http
PATCH /api/external/image-templates/{id}
```

请求体字段均可选，未传字段保持原值：

```json
{
  "name": "A+ 标准模板 V2",
  "tags": ["A+", "Amazon", "新版"],
  "note": "已更新"
}
```

注意：

- 传入 `items` 时会删除原有全部图片条目，再用新数组整组替换。
- 不传 `items` 时保留原图片条目。
- `groupName` 传空字符串可移出分组；传入不存在的名称会自动创建个人分组。
- 系统模板、其他用户的个人模板不能编辑。

成功响应为更新后的完整模板对象。

### 7.3 删除个人模板

```http
DELETE /api/external/image-templates/{id}
```

无需请求体。

成功响应：

```json
{
  "success": true
}
```

删除为软删除。系统模板和其他用户的个人模板不能通过该接口删除。

Axios 示例：

```ts
await axios.delete(`${baseUrl}/api/external/image-templates/10`, {
  headers: {
    "X-API-Key": apiKey,
    "X-User-Phone": "13800001234",
  },
})
```

### 7.4 追加图片条目

```http
POST /api/external/image-templates/{id}/items
```

请求体由单个图片条目写入字段组成：

```json
{
  "name": "卖点图",
  "prompt": "展示产品三大核心卖点",
  "aspectRatio": "1:1",
  "textAmount": "常规",
  "resolutionTier": "2K"
}
```

条目会追加到模板末尾，成功响应为追加后的完整模板对象。只能追加到当前用户自己的个人模板。

### 7.5 复制模板

```http
POST /api/external/image-templates/{id}/copy
```

请求体：

```json
{
  "name": "A+ 模板副本",
  "groupName": "我的收藏"
}
```

`name`、`groupName` 均可选：

- 不传 `name`：默认在原模板名后追加“`-副本`”。
- 不传 `groupName`：沿用源模板分组名，并在当前用户下创建或复用同名个人分组。

可以复制系统模板或当前用户自己的个人模板；成功响应为新建的个人模板对象。

### 7.6 批量导入模板

```http
POST /api/external/image-templates/import
```

请求体：

```json
{
  "ids": [10, 11, 12]
}
```

`ids` 必须包含 1–100 个正整数。重复 ID 会自动去重；不存在或已删除的 ID 会被跳过，不会导致整个请求失败。

成功响应：

```json
{
  "requested": 3,
  "importedCount": 2,
  "skippedCount": 1,
  "skippedIds": [12],
  "imported": [
    { "sourceId": 10, "newId": 101, "name": "A+ 标准模板" },
    { "sourceId": 11, "newId": 102, "name": "产品主图模板" }
  ]
}
```

导入后的模板全部成为当前用户的个人模板。源分组名在当前用户下已存在时，会创建“`-副本`”“`-副本2`”等新分组，不会并入原有同名分组。

## 8. 个人分组写接口

### 8.1 新建个人分组

```http
POST /api/external/image-templates/groups
```

请求体：

```json
{
  "name": "Amazon"
}
```

`name` 最长 50 个字符，前后空格会被移除。同一用户下分组名重复返回 `409`。

成功响应：

```json
{
  "id": 2,
  "name": "Amazon",
  "count": 0
}
```

### 8.2 重命名个人分组

```http
PATCH /api/external/image-templates/groups/{id}
```

请求体：

```json
{
  "name": "Amazon A+"
}
```

成功响应：

```json
{
  "id": 2,
  "name": "Amazon A+"
}
```

只能重命名当前用户的个人分组；与已有个人分组重名返回 `409`。

### 8.3 删除个人分组

```http
DELETE /api/external/image-templates/groups/{id}
```

无需请求体。

成功响应：

```json
{
  "success": true,
  "deletedTemplateCount": 3
}
```

该操作会同时软删除分组内的个人模板，然后删除分组。调用前应向用户明确提示影响范围。

## 9. 错误响应

所有错误使用统一结构：

```ts
interface ApiError {
  statusCode: number
  message: string | string[]
  timestamp: string
}
```

示例：

```json
{
  "statusCode": 403,
  "message": "账户已停用",
  "timestamp": "2026-08-20T03:10:00.000Z"
}
```

常见错误：

| HTTP 状态码 | 常见 `message` | 含义 | 调用方处理建议 |
| --- | --- | --- | --- |
| `400` | 参数校验错误数组 | 字段类型、长度、范围或枚举不合法 | 修正请求，不要原样重试 |
| `400` | `X-User-Phone 请求头不能为空` | 手机号请求头缺失或为空 | 补充手机号请求头 |
| `400` | `X-User-Phone 长度不能超过 20 个字符` | 手机号请求头过长 | 修正手机号请求头 |
| `401` | `X-API-Key 不正确` | 密钥缺失或错误 | 停止重试并检查密钥 |
| `403` | `账户已停用` | 目标用户已停用 | 停止操作 |
| `403` | `无权访问该模板` / `无权操作该模板` | 模板不属于目标用户 | 检查手机号和模板 ID |
| `403` | `系统模板请在「内置提示词管理」中维护` | 尝试修改系统模板 | 改为复制系统模板 |
| `404` | `无此账户信息` | 手机号不存在 | 按无账户处理 |
| `404` | `模板不存在` | 模板不存在或已删除 | 刷新模板数据 |
| `404` | `分组不存在` | 分组不存在或不属于用户 | 刷新分组数据 |
| `409` | `分组名已存在` | 当前用户下存在同名分组 | 使用其他名称 |
| `503` | `外部模板接口密钥未配置` | 服务端未配置接口密钥 | 联系接口提供方 |
| `500` | `服务器内部错误` | 未预期服务端异常 | 有限次数退避重试并告警 |

### 10.4 Node.js/TypeScript 通用客户端

```ts
const baseUrl = "https://api.example.com"
const apiKey = process.env.EXTERNAL_IMAGE_TEMPLATE_API_KEY!
const userPhone = "13800001234"

async function callImageTemplateApi<T>(
  path: string,
  method: "POST" | "PATCH" | "DELETE",
  body?: Record<string, unknown>
): Promise<T> {
  const response = await fetch(`${baseUrl}/api/external/image-templates${path}`, {
    method,
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": apiKey,
      "X-User-Phone": userPhone,
    },
    body: body ? JSON.stringify(body) : undefined,
    signal: AbortSignal.timeout(15_000),
  })

  const data = await response.json()
  if (!response.ok) {
    throw new Error(`生图模板接口失败：${response.status} ${JSON.stringify(data)}`)
  }
  return data as T
}
```

## 11. 重试、超时和幂等性

- 调用方应设置连接和总请求超时，建议总超时 10–30 秒。
- `400`、`401`、`403`、`404`、`409` 不应对完全相同的请求自动重试。
- 网络中断或 `500` 可有限次数指数退避重试，例如 1 秒、2 秒、4 秒。
- `503` 且提示“外部模板接口密钥未配置”时，重试不能解决问题，应联系接口提供方。
- 查询接口天然可安全重试。
- 新建、复制、导入和追加条目接口没有幂等键；调用方在响应丢失时直接重试可能产生重复数据，应先查询确认或在调用方记录请求状态。
- 编辑和软删除接口可按业务结果谨慎重试。
- 删除分组会连带软删除组内模板，调用方不得自动重试或在未确认用户意图时调用。

## 12. 服务端配置

接口提供方在服务端环境变量中配置：

```env
EXTERNAL_IMAGE_TEMPLATE_API_KEY="高强度随机密钥"
```

配置要求：

1. 建议使用密码学安全的随机值，长度不少于 32 字节。
2. 示例配置文件只能保留空值，真实密钥不得提交到代码仓库。
3. 修改密钥后需要重启或重新部署 API 服务，并同步通知调用方安全轮换。
4. 未配置该变量时，所有外部生图模板接口返回 HTTP `503`。
