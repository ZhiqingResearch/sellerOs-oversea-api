# 视频分析记录接口

所有接口均需 `Authorization: Bearer <token>`，查询、删除只允许操作当前登录用户的记录。

## 自动保存与 SSE

继续使用 `POST /api/video-analysis`，请求参数无需调整。AI 结果解析、归一化成功后自动保存，再发送 `result` 事件：

```json
{
  "type": "result",
  "recordId": "48efab82-71c1-4d4e-a626-5bc0ac351e53",
  "model": "ZQ-Multimodal-Gemini-3.5-Flash-Lite",
  "data": { "title": "开箱视频", "overview": "概览" }
}
```

示例省略 `data` 中其它字段，实际仍是完整的 `VideoAnalysisResult`（hook、audio、scenes、shots 等）。事件类型和结束标记保持原协议。

- 保存视频 URL、时长、关注点、MIME 类型、模型、完整结果、token 用量、分模态输入用量和扣费事件快照。
- 客户端断开后，后端仍继续分析、扣费和保存，前端可随后查询列表。
- 扣费失败时保留原有降级行为：仍保存并返回分析结果，记录的 `charge.ok=false`，可展示其 `message`。
- 预检失败、网关失败、视频未收到或结果解析失败时，不生成分析报告记录；计费流水保持原有规则。
- 保存失败时返回中文 SSE `error`，不发送 `result` 或 `[DONE]`。使用原 `chargeRequestId` 重试，计费沿用原幂等键；若尚无已保存报告，可能再次调用模型。

同用户、同 `chargeRequestId`、相同规范化参数的已保存请求会重放首次报告，不再调用模型、预检余额或扣费；成功扣费事件附 `duplicate: true`。首次报告不会被重试覆盖。同键改变视频、时长、关注点、MIME 类型或解析后的模型会返回 SSE `error`，应为新的分析生成新的请求编号。已删除记录不能以原编号重新分析或恢复。

## 历史列表

`GET /api/video-analysis/records?page=1&pageSize=10`

`page` 默认 1；`pageSize` 默认 10，范围 1–100。按创建时间倒序，相同时间按记录 ID 倒序。仅返回未删除的本人记录，列表不携带完整报告。

```json
{
  "items": [
    {
      "recordId": "48efab82-71c1-4d4e-a626-5bc0ac351e53",
      "title": "开箱视频",
      "videoUrl": "https://cdn.example.com/video.mp4",
      "duration": 30,
      "model": "ZQ-Multimodal-Gemini-3.5-Flash-Lite",
      "charge": {
        "type": "charge",
        "ok": true,
        "creditsCharged": "5",
        "balance": "120",
        "costCny": "0.5",
        "breakdown": [{ "bucket": "RECHARGE", "amount": "5" }]
      },
      "createdAt": "2026-10-07T00:00:00.000Z"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 10,
  "totalPages": 1
}
```

## 记录详情

`GET /api/video-analysis/records/:recordId`

返回列表中的全部字段，另含：

| 字段 | 说明 |
| --- | --- |
| `chargeRequestId` | 本次分析的原始请求编号 |
| `focus` | 规范化关注点，未填写为 null |
| `mimeType` | 分析使用的视频 MIME 类型 |
| `result` | 完整的分析结果，对应 SSE 的 `data` |
| `usage` | promptTokens / completionTokens / thinkingTokens / totalTokens |
| `usageDetail` | videoInputTokens / audioInputTokens / textInputTokens |

模型、用量和积分是首次分析时的快照，不随后续模型目录、价格或钱包余额变化。

## 删除记录

`DELETE /api/video-analysis/records/:recordId`

成功返回 **204，无响应体**。软删除后列表不再展示、详情不可查询，计费流水保留，不退款、不删除视频源文件。删除他人记录、不存在的记录或再次删除均返回 404「视频分析记录不存在」；非法 UUID 返回 400。

## 数据库部署

新增 `VideoAnalysisRecord` 表，按项目规范使用 schema 同步，不使用 migrate：

```bash
npm run db:push
npx prisma generate
npm run build
```

上线前需先完成数据库同步。旧的视频分析只有扣费流水，没有完整结果，无法自动补回报告；新历史列表仅包含接入自动保存之后的成功报告。工作台原有基于用量流水的次数统计保持原口径，删除报告不会删除计费或用量统计。
